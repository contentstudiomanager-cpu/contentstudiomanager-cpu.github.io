Privacy Policy — ACF YouTube Ops

This policy describes how ACF YouTube Ops (OAuth app "ACF Veille Commentaires") handles data obtained through Google and YouTube APIs.

Data accessed

  • Information about the signed-in user's own YouTube channels and videos (titles, descriptions, tags, status, schedule).
  • Public comments posted on those videos, including the commenter's public display name.
  • Aggregated statistics for those channels and videos from YouTube Analytics.

How data is used

Data is used only to manage the operator's own channels: replying to comments, editing video metadata, scheduling and uploading videos, and reviewing performance. No data is used for advertising, profiling, or any other purpose.

Storage

OAuth tokens and working data are stored locally on the operator's computer only, with restricted file permissions. Nothing is stored on third-party servers by this tool.

Sharing

Data is never sold, rented, or shared with third parties. Comment text may be processed by an AI model solely to draft a reply on the operator's behalf.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account permissions. Locally stored data can be deleted on request.
