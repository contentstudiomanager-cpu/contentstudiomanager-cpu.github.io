ACF YouTube Ops

ACF YouTube Ops (OAuth app "ACF Veille Commentaires") is a private internal tool used to manage a small group of YouTube channels operated by the same creator.

It uses the YouTube Data API and the YouTube Analytics API to:

  • read comments on the operator's own videos and post replies;
  • update titles, descriptions, tags, thumbnails and scheduling of the operator's own videos;
  • upload videos to the operator's own channels;
  • read the operator's own channel and video statistics (views, watch time, audience retention).

The tool is not offered to the public. It only acts on channels whose owner has signed in and granted access.
